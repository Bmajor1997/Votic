# Google Play store images

Images for Votic's Play Store listing (Play Console → Grow users → Store presence → Store listings → Default store listing).

| File | Where it goes | Size |
|---|---|---|
| `votic-icon-512.png` | App icon | 512 × 512 |
| `votic-feature-graphic-1024x500.png` | Feature graphic | 1024 × 500 |
| `votic-screenshot-1-listen.png` … `votic-screenshot-6-home.png` | Phone screenshots, in number order | 1080 × 1920 |

Screenshots were captured from the app on the Android emulator using NASA's public-domain "Sun: Facts" and "Moon Facts" pages as sample documents, then given a caption on Votic blue (#2563EB). The listing text (name, short and full description) is in the "Votic Google Play Listing" doc.
